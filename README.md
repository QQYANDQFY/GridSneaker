# GridSneaker · 网格移动动画模拟平台

一个纯前端、零依赖的网格移动动画模拟平台：在方格 / 六边形网格上驱动「蛇形移动体」前进，
叠加环境规则、元胞自动机与多蛇交互，并把每一步的轨迹与统计可视化出来。
全部逻辑用浏览器原生 ES Module 实现，无需构建即可运行，也可打包成单文件离线使用。

## 功能特性

### 网格与移动体

- **两种网格**：方格与六边形，宽高、格子像素、间距均可调；
  元胞自动机与感知条件支持摩尔 / 冯·诺依曼 / 六边形邻域与可调半径。
- **四种边界行为**：`穿越到另一侧`（默认）· `反弹` · `停止` · `随机转向`，
  以及由用户定义的自定义边界策略；穿越模式在画面四角同样可正确算出可走方向。
- **可配置起点与初始身体**：起点坐标 / 朝向、初始长度、头粗尾细的体节渲染、身体连接方式（直线 / 角度切角 / 贝塞尔曲线）。
- **转向权重**：左 / 直 / 右 / **停止** 四项的加权随机（「停止」默认权重为 0，被选中时不产生任何有效位移，
  判定链与「尝试移动到障碍物」完全一致），另有条件概率规则（按状态、朝向、步数等条件覆盖权重）。
- **长度策略**：增长 / 缩减各自独立的触发条件（步数、吃到标记物、达成条件）、数量与概率。
- **安全避撞与碰撞处理**：可选择规避自身身体 / 障碍物 / 其它移动体；自撞后可结束、掉头、随机转向或直接穿行；
  并可选**避撞触发后的处理方式**——`自动切换其他可行方向继续运动`（默认，与旧版一致）或
  `立即停止运动`（避撞介入时本步原地停止，计入「停止次数」并按「撞到障碍物」规则收尾）。

### 环境与规则

- **环境感知—条件—后果规则**：`感知范围 + 条件 + 后果` 三段式，后果支持转向、增长、缩减、变色、生成 / 销毁标记物、写入状态等，
  按优先级依次匹配，可在面板内启用 / 停用与排序。
- **元胞自动机（CA）**：可独立运行或与移动体混合运行，内置多种经典规则（生命游戏等）、
  规则表编辑、状态配色与「快捷模板」一键套用。设置面板按配置时的思考顺序收敛为
  **核心规则 / 演化规则 / 初始环境 / 运行与性能 / 交互与模板** 五个子选项卡
  （启用开关固定在子选项卡之上，任何子页都可见），面板不再是一条需要反复滚动的长列表；
  搜索时全部子页自动展开，命中项不会藏在未激活的子页里。
- **可复用的 CA 配置资产**：规则表支持**规则集导入 / 导出**（复制或下载为 JSON，
  只含规则表本身，可跨场景、跨用户传递，导入时对状态名不匹配给出中文警告）；
  初始环境支持**环境模板**保存与复用（＝状态集合 + 初始状态 + 手绘格子，
  不含移动体 / 规则 / 外观）；演化参数支持**参数预设**
  （邻域 / 半径 / 边界 / 更新顺序 / 同步方式 / 演化间隔 / 稳定判定 / 初始状态），
  可在同一套环境上快速对比不同参数组合。三处记录都保存在浏览器本地，可随时载入或删除。
- **交互反馈**：融合 / 排斥 / 生成 / 标记物反馈等交互事件在画面上以脉冲特效呈现。
- **画布格子编辑器**（默认关闭）：开启后，画布上的鼠标左键单击由「跳到首次经过的步数」切换为
  **直接增删格子元素**——单击添加、再次单击删除；点击坐标经
  `Renderer.hitTest` 反查行列号，与绘制几何完全一致（无交互偏移）。编辑工具含
  **标记物 / 障碍物 / 元胞自动机状态 / 擦除**四种：其中「元胞自动机状态」可显式指定任意非空环境状态
  （如生命游戏的「存活」），选「自动」时取状态集合中的首个非空状态，面板实时回显本次点击将放置的状态。
  放置时机可选**「初始环境（写入第 0 步）」**或**「当前步放置」**：前者是环境演化的起点，
  后者把格子写入当前所在步数、只影响该步及其之后的帧，**不回溯改写已完成的模拟帧**
  （重算后自动跳回放置所在步，便于连续编辑；每次放置都会写入运行日志，可按日志回溯）。
  同一开关下还提供**默认开启的拖拽连画**（按住左键拖动即连续绘制，起手格已放置则为连擦）、
  右键擦除、画笔尺寸（1~9 格）、按密度一键随机散布、撤销 / 重做（上限可调；快照同时覆盖
  初始环境与延迟放置，撤销不会丢补丁）、清空全部手绘 / 清除本步放置 / 清空全部延迟放置
  （破坏性操作先经确认）与已绘制格子计数。
  编辑模式开启时画布光标切换为十字准星。绘制的格子随配置保存与分享，并在模拟开始时写入世界，
  等价于「自定义初始环境」。若已启用编辑器但第 0 步既没有手绘格、元胞自动机的初始状态
  也等价于「全空」，面板会给出醒目警告「第 0 步还没有初始环境」并提供「去配置初始环境」一键跳转，
  避免运行后才发觉画面上没有任何环境单元、观测不到模拟变化。
- **自定义标记物类型**：为交互标记物新增「类型层」——同一状态可挂多个类型，各自带
  **外观样式 / 生效条件（始终 · 概率 · 长度上下限 · 步数门槛）/ 触发权重 / 内置反馈**，
  运行时先按条件过滤、再按权重抽取一个生效类型。列表默认为空，行为与旧版完全一致；
  后续新增标记物只需追加一条记录，无需改动模拟主循环。
- **障碍物陷阱**：为自定义障碍物类型附加陷阱属性，可分别设置**触发概率**与**死亡概率**
  两级可调参数（1 = 必定、0 = 从不）。蛇尝试移动到陷阱格时先判定是否触发、再判定是否致命，
  未致命则退回普通障碍物阻塞；每次判定都会写入运行日志（可关闭），便于调试。
- **障碍物交互式放置**：支持「先选自定义障碍物类型再点击格子精准放置」，以及
  「开启随机放置模式后按设定概率从随机池中抽取类型」两种模式，两种模式均支持再次点击删除。

### 多蛇与统计

- **多蛇生成与交互**：批量生成多个移动体，相遇时按设置执行碰撞、融合、排斥或穿行。
- **实时 / 总计双口径统计**：步数、长度、覆盖率、转向分布、死亡 / 结束原因等，
  坐标筛选查询内嵌于统计模块，与统计共用同一轨迹数据源并实时同步。
- **统计项显示配置**：生成新蛇、移动体消失、融合 / 排斥次数、生命机制等**低频统计项默认隐藏**，
  只保留步数、长度、覆盖率、碰撞等高频核心读数，统计面板不再拥挤；隐藏项可逐项勾选开启，
  并提供「仅核心指标 / 全部显示 / 全部隐藏 / 恢复默认」整组预设，当前显示条数实时提示。
  隐藏只影响统计格与摘要行的生成，统计与导出数据不受影响。
- **得分与难度**：把一轮运行折算为「总分 + 等级 + 6 个透明分项」，最高分按地图指纹持久化；
  拥挤度驱动的动态难度可在拥挤时自动放慢播放。
- **轨迹工具**：轨迹渐隐（线性 / 指数）、轨迹颜色分级（按新旧渐隐 / 按经过次数热度 / 按经过次序）、
  轨迹尖端平滑过渡、**轨迹方向箭头**（沿已播放轨迹按间隔标注前进方向，间隔 / 尺寸 / 颜色可调）、
  **热点轨迹过滤**（只绘制经过次数达到阈值的轨迹段，一眼看出反复踩踏的热点路径）、
  **边界进出点独立显示**（与轨迹主体完全分离、默认关闭，尺寸可调）与进出事件日志、
  轨迹快照对比、按坐标筛选高亮、重访格高亮（判定次数与不透明度可调）、跟随移动体视图。
- **环境演进观察**：**本步变化高亮**把「当前步相对上一步环境状态发生变化」的格子标出来
  （元胞演化、标记物生成 / 消耗、障碍物变化等），不透明度与颜色可调。
- **悬浮提示**：鼠标悬浮格子即展示该格详情，内容与当前已开启的显示项**严格同步**
  （环境状态 / 移动体 / 轨迹信息 / 标记信息逐项可开关，未开启的显示项不会出现在提示里）；
  轨迹信息除次序、首次 / 末次步数外，还给出**当前路径经过次数**（截至当前播放进度）与
  **历史累计经过次数**（整轮累计，含上次经过的步数）；
  画面中**只有一条移动体**时「历史累计经过次数」与轨迹行的整轮总数完全同值，会按
  **单蛇提示精简**开关（默认开启）自动省略，多移动体场景两条口径并存；
  可另行开启悬停行列准线（宽度可调）。

### 外观与导出

- **自定义皮肤（上传图片）**：分别上传 **蛇头** 与 **蛇身** 图片，支持 **JPG / PNG / WebP**；
  蛇头按朝向裁切贴图，蛇身以「轮廓蒙版 + 图案填充」合成，跨越边界时镜像副本同样贴图。
- **展示样式**：暗黑 / 亮色主题、轨迹 / 身体 / 箭头 / 坐标轴 / 网格线 / 起点终点 / 障碍物 / 标记物 /
  边界进出点 / 特效 / 发光 / 重访格高亮 / 悬停行列准线 / 悬浮提示等逐项开关。
- **视觉设置分类**：「视觉显示」类别下按功能拆分为 **基础视觉设置 / 高级视觉特效 / 悬停与提示 /
  色彩主题配置** 四个折叠分组，与其它类别层级完全一致（主选项卡 → 折叠分组 → 字段），
  选项按功能归类，界面不再拥挤；搜索设置项时命中项不会被藏起。
- **术语说明浮层**：统计面板的统计格与「统计项显示配置」的复选框文字带虚线下划线（`cursor: help`），
  鼠标悬停即显示该指标的统计口径说明（如「覆盖率」= 去重格子数 / 网格总格数、「CA 演进次数」=
  元胞自动机的更新代数），由 `STAT_TERMS` 术语表统一维护。
  **交互标记物状态 chips** 同样在右侧带「?」入口，悬停弹出说明面板，逐条解释该标记物的
  **功能 / 生效规则 / 使用场景**；面板复用同一浮层节点、随视口自动定位，不遮挡核心操作区域，
  其中用户自定义名称会先转义再写入，避免破坏浮层结构。
- **选项卡配色与排版**：选项卡配色抽取为 CSS 自定义属性，已激活 / 未激活两态背景色、文字色、边框色
  可逐项自定义（取色器 + 十六进制输入，附实时预览与一键重置），默认值刻意拉大两态色差；
  另提供**紧凑排版**（压缩分组 / 字段 / 开关行 / 统计格间距）与**统计切换淡入**开关。
- **统一开关行**：核心规则等板块的开关统一为「标签左 / 控件右 + 说明独占一行」的两列网格布局，
  固定行高保证所有开关、标签与说明文本落在同一基线上，对齐一致。
- **配置导入导出**：JSON 复制与下载、分享链接（`#c=…`）、粘贴 JSON 导入、前端配置诊断。
- **结果导出**：轨迹 CSV / JSON、日志 CSV / JSON、当前帧 PNG / SVG、纯轨迹 SVG、轨迹明细 CSV。

## 快速开始

### 方式一：直接打开单文件（推荐给最终用户）

双击仓库根目录下的 `GridSneaker.html`，浏览器即可运行，无需服务器、无需联网、无需安装任何依赖。

### 方式二：本地开发（可读源码 + 热刷新）

需要 Python 3（仅用于起静态服务器）或任意静态服务器：

```bash
npm start          # 等价于 python -m http.server 8080
```

然后访问 <http://localhost:8080/>。
注意：`index.html` 通过 ES Module 加载 `src/`，**必须经 HTTP 访问**，直接双击会被浏览器的模块跨域策略拦截。

## 使用说明

### 控制条

- ▶ 播放 / 暂停 · ◀ 上一帧 · 单步 ▶ · ⟲ 重置 · ⏭ 跳到末尾 · **重新计算**（按当前配置重跑一轮）
- 循环、自动运行、跟随移动体、自适应速度
- 速度滑块（0.5 ~ 120 步/秒）与速度档位按钮（0.5 / 2 / 8 / 30 / 120）
- 随机种子（同一种子结果完全可复现）与「🎲」随机换种子
- 时间轴拖拽跳帧、当前帧 / 总帧数、结束原因与「查看结束规则」「继续运行 +20000」

> 页面加载后即按当前配置自动跑完一轮（可取消勾选「自动运行」），因此首次打开就能直接回放与观察统计。

### 侧边面板

- **配置面板（左）**：所有设置分组**默认全部收起**，点击分组标题即可展开；
  顶部搜索框可按关键词过滤分组并自动展开命中项，清空后还原原有折叠状态；
  「清除」按钮悬停即给出完整说明（清除范围仅限搜索框内容，不改动任何已保存的设置项）；
  面板顶部另有「展开全部 / 收起全部」一键操作。
  分组顺序：场景与随机 · 网格与坐标 · 移动体与身体 · 移动规则 · 碰撞与自撞处理 ·
  多蛇生成与交互系统 · 环境感知—条件—后果规则 · 元胞自动机模式 · 结束规则（按优先级）· 展示样式
  （「展示样式」内部再分「基础视觉设置 / 高级视觉特效 / 悬停与提示 / 色彩主题配置」四个折叠分组，
  与其它类别层级一致，不再有第三层容器）。
- **统计与日志面板（右）**：预设模板 · 配置导入导出 · 导出结果 · 统计模块（含坐标筛选查询与
  「统计项显示配置」）· 轨迹快照对比 · 规则触发日志 · 配置诊断，同样默认收起。

### 边界行为

- **穿越到另一侧（默认）**：蛇头触碰画布边界时从对侧对应位置重新出现，画面会绘制方向明确的穿梭光带；
  跨缝的体节链会整体平移出镜像副本，保证蛇身视觉连续。
  **轨迹同样跨缝连续**：轨迹按「连续展开坐标 + 每段整圈平移量」解算并裁剪到网格区域，
  滑出侧一直画到边界、滑入侧从对侧接着画，因此边界网格的轨迹覆盖率是 100%，
  不会出现「靠近边界的网格只显示一半轨迹」或「跨缝轨迹整段缺失」。
- **反弹**：撞墙后掉头，永不越界；**反弹时自动启用安全避撞**——
  贴边掉头若反向格正好压在自己的身体上（撞到自己的脖子）或落在界外，
  会自动改选一个「界内 + 未被阻塞 + 不撞自身」的方向，避免被误判为自撞死亡。
  该机制仅在反弹模式下生效，穿越等其它边界策略的行为完全不变。

### 自定义皮肤

1. 展开左侧「移动体与身体 → 自定义皮肤（上传图片）」。
2. 在「蛇头皮肤」「蛇身皮肤」中点击**选择图片**，选择本地的 JPG / PNG / WebP 图片。
3. 上传后会立即渲染到画布；点**清除**可恢复纯色 / 渐变配色。

校验规则（任一不通过都会保持原皮肤不变并提示原因）：

- **格式**：仅 `.jpg` / `.jpeg` / `.png` / `.webp`；
- **体积**：单张不超过 2 MB；
- **尺寸**：每条边 16 ~ 2048 像素；
- **可解码**：文件损坏或解析失败时给出明确提示。

皮肤以 dataURL 形式保存在配置中：随「导出 JSON」一并保存，也会写入浏览器本地存储；
但**不会写入分享链接**（图片体积远超链接长度上限），分享链接载入后皮肤为未设置状态。

## 构建单文件

```bash
npm run build                       # 生成 GridSneaker.html（内联 + 压缩）
node tools/build-single-file.mjs --no-minify   # 生成未压缩的 GridSneaker.raw.html，便于排查问题
```

打包脚本按依赖顺序把每个 ES Module 包成 IIFE，通过 `__MODULES` 表传递导出，避免模块间同名声明冲突；
产物中的 JS / CSS 会去掉注释与缩进（保留换行以保证 ASI 语义不变），源码本身保持完整可读。
产物中的版本号取自 `package.json`，无需手工同步。

## 测试

```bash
npm test              # 等价于 node tests/core.test.mjs
```

测试为自研的无依赖框架（`ok` / `eq` / `near` / `section`），覆盖网格与边界行为、模拟主循环、
规则与条件求值、元胞自动机、得分与难度、轨迹模型、配置规范化 / 校验 / 诊断 / 差异比对、
皮肤格式校验与分享链接剥离、渲染层跨缝连续性（含边界网格轨迹覆盖率 100%）、
轨迹颜色分级 / 尖端平滑 / 边界进出点独立显示与悬浮提示同步 / 访问回溯与重访高亮等，
另含「视觉折叠分组 / 统计项显示配置 / 开关行排版 / 选项卡配色 / 统计术语浮层 / 安全避撞开关联动 /
环境写入置脏 / 播放合并重绘 / 搜索防抖 / 长跑运行提示 / 元胞状态格子放置 / 避撞处理方式 /
CA 子选项卡分类及其搜索联动 / 延迟放置（仅本步生效、不回溯历史帧）/ 第 0 步缺环境警告 /


## 部署

本项目是纯静态站点，构建产物为单个 HTML 文件，可直接部署到任意静态托管：

- **GitHub Pages**：把仓库推送到 GitHub，在 `Settings → Pages` 中选择分支（如 `main`）与根目录 `/` 保存，
  稍后访问 `https://<用户名>.github.io/<仓库名>/` 即可（`index.html` 会被自动识别为入口）。
- **其它静态托管**（Netlify / Vercel / Cloudflare Pages / 对象存储等）：无需构建命令，
  直接上传仓库内容或把发布目录指向仓库根目录即可。
- **离线分发**：只需分发 `GridSneaker.html` 一个文件，收件方双击即可使用。

本地预览打包产物：

```bash
python -m http.server 8080   # 访问 http://localhost:8080/GridSneaker.html
# 或直接双击 GridSneaker.html（单文件版本无同源限制）
```

## 浏览器兼容性

需要支持 ES Module、`Canvas 2D`、`ResizeObserver`、`localStorage` 的现代浏览器
（Chrome / Edge / Firefox / Safari 的近年版本）。
360、QQ 等双内核浏览器请使用**极速模式**；若脚本未能启动，页面会给出切换内核的提示。
